# Security Policy

## Desteklenen Sürümler

Şu anda yalnızca en güncel `V11` sürümü güvenlik ve performans güncellemeleri almaktadır.

| Sürüm | Destek Durumu |
| ------- | ------------------ |
| V11.x   | :white_check_mark: |
| V10.x   | :x:                |
| < V10   | :x:                |

## Güvenlik Bildirimi & Anti-Cheat

Purple Hub V11, herhangi bir zararlı yazılım (malware, logger vb.) içermez. Kod tamamen açık kaynaklıdır ve istemci tarafında (Client-Side) çalışır.

- **Crash & Freeze Riskleri:** Oyun içi donmaları engellemek için `task.wait()` ve `RunService` entegrasyonu kullanılmıştır.
- **Hata Bildirimi:** Script ile ilgili bir çökme veya güvenlik sorunu fark ederseniz lütfen GitHub üzerinden bir **Issue** oluşturun.
